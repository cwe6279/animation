Configuration reference

Every knob on the talking face, and which file it lives in

Talker is a projected character that listens, thinks, and talks back: a mascot at a park gate, a historical figure in a museum gallery, a storyteller in a library. This page lists what you can change, where, and what we measured when choosing the defaults.

Overview

What runs where

One turn passes through six stages. Local stages cost CPU on the box running the face; cloud stages cost the same on a Raspberry Pi as on a desktop.

localMicrophone capture, 16 kHz mono
local or cloudSpeech to text
--stt
cloudBrain, streamed
--llm
cloudVoice, sentence by sentence
--tts
localLip sync from word timings
localFace render, 30 or 60 fps

The face starts speaking the first sentence while the brain is still writing the rest. Every turn prints one [turn] line in the terminal: time from when you stopped talking to the transcript, to the first token, to the first audio. That line is the number to tune against.

Commands voice_loop.py · talker.py

Starting it

Activate the virtualenv first (source .venv/bin/activate). The conversation loop is voice_loop.py; talker.py only speaks text you give it.

# Desktop: local Whisper, Claude, ElevenLabs v3, the cat's own voice and persona
python voice_loop.py --face green_cat --mic-device gomic --output-device jabra --debug

# Raspberry Pi: everything heavy in the cloud, fullscreen, 30 fps
python voice_loop.py --face green_cat --profile pi --mic-device gomic --output-device jabra

# No mic: type in the window, replies still go through the brain
python voice_loop.py --face eve --text-only

# Just say a line (supports [tags])
python talker.py --face skull --text "[whispers] Who dares enter?"

Character library faces/<name>/face.json

Five faces so far, each with its own voice and persona

A face is a folder. The manifest carries art positions, glow colour, idle behaviour, the default voice per backend, and the persona line sent to the brain. Command line flags override any of them for one run. The current five came from a Halloween build; a face can just as well be a historical figure, a school mascot, or an exhibit's narrator.

Adding a character faces/_template/ → faces/<name>/

A new face is a folder with a manifest and optional PNGs

  1. Copy faces/_template to faces/<name> and edit face.json. Everything except the manifest is optional; missing art falls back to glowing procedural shapes.
  2. Design on an 800 by 800 canvas and export each feature as a full-canvas PNG with transparency: face_base.png, eye_left.png, eye_right.png, nose.png, and up to six mouths mouth_sil, mouth_pp, mouth_aa, mouth_oo, mouth_ee, mouth_ah. Art is cropped to its opaque bounds at load, so full canvases cost nothing at runtime.
  3. Set the persona and voice in the manifest, then run python talker.py --face <name> --debug --text "Hello" to check placement.

EVE's art is generated by a script rather than drawn: edit the numbers at the top of faces/eve/generate_art.py and rerun it to reshape the head, visor, or eyes. To have an image model draw a face instead, hand it faces/ART_SPEC.md: it fixes the canvas, the layer set, the file names, and the mouth shapes so the output drops straight into a face folder.

Prompt and tags llm_integration/system_prompt.md

One shared prompt, one persona line per face

Everything below the "System Prompt" heading in system_prompt.md is sent to the brain on every turn, with the face's character appended as "Character: …". The prompt teaches the performance-tag vocabulary and the rules: tags go before the words they colour, must fit the content, and most sentences should have none. A short voice rule keeps replies to one to three sentences with no markdown.

How tags reach the voice and the eyes

Tags are the ElevenLabs v3 vocabulary: emotional states, reactions, tone cues, character cues. The voice performs them only on ElevenLabs v3; Flash and edge get them stripped so nothing reads "sigh" aloud. Separately, tags with an emotional meaning move the eyes:

EyesTags that trigger it
happy, smiling squinthappy, excited, cheerfully, playfully, laughs, giggle, chuckle, light chuckle, sigh of relief, warmly, proud, teasing
angry, narrowed and furrowedangry, frustrated, furious, shouting, growls, menacing
annoyed, mild narrowannoyed, irritated, sarcastically, whiny, deadpan, bored, exasperated, smug
sad, droopedsad, sorrowful, tired, regretful, resigned tone, hesitant, sigh, quietly, softly, weary
surprise, wide opensurprised, gasps, awe, amazed, shocked, curious, scared, nervous, confused
neutralcalm, flatly, matter-of-fact, whispers, serious, thoughtful

Accents, roles and beats like [pauses] affect only the voice. The map is TAG_TO_EMOTION in phoneme_scheduler.py; add words there to teach the eyes new tags.

If the face feels busy: every model we tested tags more than the prompt asks, about two per reply. Tighten rule 3 in the prompt. For a longer persona, a historical figure's biography, speech habits, and the facts it should stick to, the character string can be as long as you like; the shared prompt handles delivery, the persona handles who is speaking.
API keys .env (copy from .env.example)

Keys live in .env and never in git

Copy .env.example to .env in the project root. It is gitignored. Values already in the environment win over the file.

Audio devices voice_loop.py flags

Pick devices by name, not number

PortAudio renumbers devices whenever something is plugged in, so name fragments are safer: --mic-device gomic --output-device jabra. Matching is case-insensitive and prefers the PipeWire entry over the raw hardware one.

python voice_loop.py --list-devices                     # every input and output with its native rate
python voice_loop.py --mic-test --mic-device gomic      # levels and live transcripts, nothing else
python voice_loop.py --mic-test --mic-device gomic --record recordings/   # also save clips for the benchmark
  • Levels. Aim for 500 to 5,000 while talking on the mic test's scale; peaks above about 28,000 clip. Adjust gain in the system sound settings.
  • Rates. Devices open at whatever they support and are resampled, so a 48 kHz speakerphone plays 24 kHz speech and a 48 kHz mic feeds a 16 kHz recognizer. --mic-rate forces the mic's open rate.
  • Silence. --silence-ms sets how long a pause ends your turn. Default 600 for local recognizers, 500 for cloud. Lower feels snappier and cuts more sentences.
  • Echo. The mic is ignored while the face speaks. --barge-in keeps listening and interrupts when you talk, which needs headphones or a mic that cannot hear the speaker.

Profiles

--profile pi sets cloud speech to text (Groq, or ElevenLabs without a Groq key), the Groq brain when a key is present, fullscreen, 30 fps, and thinking off. Any flag you pass explicitly still wins, so --llm claude keeps Claude's writing on the Pi at about a second per reply.

Test tools tests/ · bench_stt.py · bench_llm.py

Prove it before you trust it

pytest tests                                  # 36 tests, no mic or display needed
python bench_stt.py --synth                   # recognizers on clean and noisy synthesized clips
python bench_stt.py recordings/               # the same on your own recorded clips
python bench_llm.py                           # brains: speed and how well they follow the tag spec
python voice_loop.py --mic-test --mic-device gomic --stt elevenlabs   # try a recognizer live

For your own clips, record with --mic-test --record recordings/, then correct the draft lines in recordings/transcripts.txt before running the benchmark.

Troubleshooting

When it misbehaves

SymptomLikely cause and fix
It speaks "Sorry, I could not think of an answer"The brain call failed. The terminal has an [error] LLM failed line: usually a missing or unscoped key, or no credits.
Mic never hears anythingWrong device or gain. Run --mic-test and check the level line; pick the device by name.
Every turn is exactly 15 seconds longRoom noise above the endpointer's threshold. Fixed in the current build; if it recurs, lower the mic gain.
"Invalid sample rate" or "no default output device"Old builds. Devices now open at any supported rate and fall back to another output.
Voice "does not exist" on ElevenLabsAdd the community voice to My Voices, and give the key the voices permission.
Lips early or late--sync-offset in 0.02 s steps with the debug overlay on.
Face reads "sigh" out loudOnly ElevenLabs v3 performs tags; every other voice strips them. Check --tts-model.
PyAudio will not installNeeds the Python headers and PortAudio: dnf install python3-devel portaudio-devel, then pip install pyaudio.
